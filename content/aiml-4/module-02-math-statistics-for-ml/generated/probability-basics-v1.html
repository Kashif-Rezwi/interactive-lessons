UNIT 1 · PROBABILITY & RANDOM VARIABLES

A random variable labels every outcome with a number

CLASS CORE Probability is the mathematical language of uncertainty. Modern AI systems do not make "certain" decisions — they make probabilistic predictions. Every model answers questions like: how likely is this email to be spam? what is the probability this transaction is fraud? which next token is most probable? what is the likelihood this user clicks? source

ML LINK Three concrete uses the source names. Large language models: when ChatGPT predicts the next word it outputs a probability distribution over the vocabulary — the source's example gives "world" 0.41, "everyone" 0.22, "people" 0.18 — and the most probable token is sampled/generated. Fraud detection: banks compute P(Fraud | transaction features); ≈0.02 reads as a safe transaction, ≈0.95 as highly suspicious. Recommendation: Netflix or Amazon estimate P(User Likes Item); ranking recommendations is fundamentally probability ranking. source

FOUNDATION A random variable maps the outcomes of a random process to numerical values — "a numerical representation of randomness." Formally:

X: Ω → ℝ
  • X — the random variable: a rule that assigns a number to each outcome
  • Ω — the sample space: every possible outcome of the process
  • ℝ — the real numbers: the labels it maps to
  • Why it makes sense: to do math on randomness we need numbers, not raw outcomes — a random variable is the bridge. How to read the result: for any outcome you can name, X hands you a number.

CLASS CORE Dice: the sample space is Ω = {1, 2, 3, 4, 5, 6}, and X = the number showing on the die, so X ∈ {1, 2, 3, 4, 5, 6}. Rainfall: X = rainfall in millimetres tomorrow, so X ∈ [0, ∞) — it can take any value in a range. source

CLASS CORE That last example is the great divide. A discrete random variable takes countable values — a die roll, the number of customers, emails, or defective products — and probabilities attach to exact values, so P(X = 3) is meaningful. A continuous random variable takes infinitely many values in an interval — height, weight, temperature, time, voltage — so the probability of any single exact point is zero, P(X = x) = 0, and instead we ask P(a ≤ X ≤ b). source

Beginner trap. "The random variable is the outcome." No — the outcome is what happens (rain fell); the random variable is the number you attach to it (3.2 mm). Two different random variables can label the same process (millimetres or inches), and the math follows the label. Keep them separate and everything downstream gets easier.

UNIT 2 · PMF (PROBABILITY MASS FUNCTION)

The PMF hands out the budget in lumps

CLASS CORE A probability distribution describes how probability is distributed over a random variable's values. For a discrete variable the rule is the probability mass function (PMF): it gives the probability at each exact value. source

P(X = x)
  • X — the discrete random variable
  • x — one specific value it can take
  • Why it makes sense: a discrete variable spends its probability in lumps at exact values, so a table or bar chart of P(X=x) is the complete description. How to read the result: P(X = 3) = 0.2 means a 20% chance of the value exactly 3.

CLASS CORE The source's dice example: a fair die has P(X = x) = 1/6 for x ∈ {1, 2, 3, 4, 5, 6}. Two properties make any PMF valid — the source shows them as a figure (opaque in the notebook); we state them plainly: source (figure recovered)

0 ≤ P(X = x) ≤ 1    and    Σₓ P(X = x) = 1
  • 0 ≤ P(X = x) ≤ 1 — every mass is a genuine probability, between impossible and certain
  • Σₓ — the sum over every value the variable can take
  • = 1 — the total budget is spent exactly once: the masses account for all certainty
  • Why it makes sense: something must happen, so the masses cannot total less than 1; and no single value can exceed certainty. How to read the result: if your masses sum to 0.9, you have missed a value; if they sum to 1.1, you double-counted.
Beginner trap. "The masses don't have to sum to 1." They must. A PMF is a budget of exactly 1.0 shared among the values; the sum-to-1 rule is not a nicety but the definition. A common slip is a die with sides 1–6 but masses that total 5/6 — that die is missing a side's worth of probability.

UNIT 3 · PDF (PROBABILITY DENSITY FUNCTION)

The PDF is a density: only its area is probability

CLASS CORE For a continuous variable the rule is the probability density function (PDF), f(x). The source's central line: probability is the area under the curve, not the height. So we never read a probability off a single point — we measure a slice. source

P(a ≤ X ≤ b) = ∫ₐᵇ f(x) dx
  • f(x) — the density: how thickly probability is packed near x (a height, not a probability)
  • ∫ₐᵇ … dx — the integral: the area under the curve between a and b
  • a, b — the ends of the interval you care about
  • Why it makes sense: a continuous variable spreads its budget over infinitely many points, so no single point can hold any of it — only a stretch of the axis can. How to read the result: a wider or taller region captures more probability; the total area over the whole support is 1.

CLASS CORE Two consequences the source stresses. First, for a continuous variable f(x) ≠ P(X = x); in fact P(X = x) = 0, because a single point has zero area. Second, the simplest example: uniform distribution X ~ U(0, 1) has

f(x) = 1   for   0 ≤ x ≤ 1
  • f(x) = 1 — a flat density of height 1 across the unit interval
  • 0 ≤ x ≤ 1 — the support: outside it the density is 0
  • Why it makes sense: a rectangle of width 1 and height 1 has area 1, so every equal-length sub-interval gets equal probability. How to read the result: P(0.2 ≤ X ≤ 0.7) = 0.5, the rectangle's width × height.
Beginner trap. "f(0.5) = 2 means a 200% chance." No — a density is not a probability and can exceed 1. The density f(x) = 2x at x = 0.9 equals 1.8, yet every probability it produces is a valid area ≤ 1. Only the area is a probability; the height is free to be any non-negative number.

UNIT 4 · CDF (CUMULATIVE DISTRIBUTION FUNCTION)

The CDF is a running total

CLASS CORE The cumulative distribution function (CDF) works for both discrete and continuous variables. It answers one question: how much probability has accumulated so far? source

F(x) = P(X ≤ x)
  • F(x) — the running total of probability up to the value x
  • X ≤ x — the event "the outcome is at most x"
  • Why it makes sense: instead of asking about one value, the CDF sweeps the axis and reports the budget spent so far — a single function that works for both variable types. How to read the result: F(x) = 0.7 means 70% of the probability lies at or below x.

CLASS CORE The source's example: X ~ U(0, 1) has F(x) = x on [0, 1], so at x = 0.2, 20% of the probability has accumulated, and at x = 0.7, 70%. For our toy density f(x) = 2x, the running total is F(x) = x². source

0 ≤ F(x) ≤ 1;   F(x) → 0 as x → −∞;   F(x) → 1 as x → +∞
  • non-decreasing — F(a) ≤ F(b) whenever a < b: probability only accumulates, never un-accumulates
  • range 0 ≤ F(x) ≤ 1 — a running total is a probability
  • right-continuous — the CDF does not jump unexpectedly from the right
  • limits — far left, nothing has accumulated (0); far right, everything has (1)
  • Why it makes sense: these four properties are the fingerprint of any valid CDF, discrete or continuous. How to read the result: if F ever decreases, or never reaches 1, it is not a CDF. source (upper limit corrected)
Beginner trap. "F(x) is the probability that X equals x." No — that is the PMF/PDF's job. F(x) = P(X ≤ x) is a cumulative total: F(3) = 1/2 for a fair die means a 50% chance of rolling 3 or less, not a 50% chance of exactly 3. The source's cell even prints the upper limit as 0; the correct limit is 1, and we use 1 throughout.

UNIT 5 · CDF ↔ PDF CONVERSION (THE HEART OF THIS LESSON)

The CDF is the area; the PDF is the slope

CLASS CORE The source's title idea: the PDF is local probability density, the CDF is total accumulated probability, and the two are two views of the same thing. The CDF is the area under the PDF; the PDF is the slope (derivative) of the CDF. source

F(x) = ∫_{−∞}^{x} f(t) dt   ⇔   f(x) = dF(x)/dx
  • ∫_{−∞}^{x} f(t) dt — accumulate the density from far left up to x (the area so far)
  • dF(x)/dx — the local slope of that running total (the density at x)
  • t — a dummy variable that sweeps the axis while x stays fixed as the upper limit
  • Why it makes sense: accumulating a rate gives a total; taking the slope of a total gives back the rate. How to read the result: start with either function and you can recover the other — integrate to go PDF → CDF, differentiate to go CDF → PDF.

CLASS CORE Because the CDF already holds all the accumulation, the probability of an interval is a subtraction — no integral needed:

P(a ≤ X ≤ b) = F(b) − F(a) = ∫ₐᵇ f(x) dx
  • F(b) − F(a) — the probability accumulated up to b minus that up to a — the slice between them
  • ∫ₐᵇ f(x) dx — the same slice measured as area under the density
  • Why it makes sense: "how much by b" minus "how much by a" isolates the interval. How to read the result: the fundamental theorem of probability — area and CDF-difference always agree.

CLASS CORE Worked example (the source's). Let f(x) = 2x on [0, 1]. Integrate to get the CDF: F(x) = ∫₀^{x} 2t dt = x². Check the far end: F(1) = 1² = 1 ✓. Reverse-check by differentiating: d/dx(x²) = 2x, recovering the original PDF. source

CLASS CORE Discrete variables use the same idea with sums. The discrete CDF is F(x) = Σ_{xᵢ ≤ x} P(X = xᵢ) — add up the masses up to x (the source's dice example: F(3) = 1/6 + 1/6 + 1/6 = 1/2). To go back, recover each mass as the jump in the CDF: source

P(X = x) = F(x) − F(x⁻)
  • F(x) — the running total including the mass at x
  • F(x⁻) — the left limit: the total just before x
  • Why it makes sense: the CDF steps up by exactly one mass at each value, so the step size is the mass. How to read the result: P(X=3) for a fair die = F(3) − F(2) = 1/2 − 1/3 = 1/6 ✓.
Beginner trap. "To get the PDF you integrate; to get the CDF you differentiate." It is the reverse. CDF = integral of PDF (accumulate), PDF = derivative of CDF (slope). A quick sanity check: a CDF must climb to 1, which only an accumulation does; a PDF can be any non-negative shape, which is what a slope can be.

UNIT 6 · EXPECTATION

Expectation is the balance point of the budget

CLASS CORE Expectation is the long-run average outcome — equivalently, the probability-weighted average. For a discrete variable it is a weighted sum, and for a continuous one a weighted integral: source

E[X] = Σₓ x · P(X = x)    (discrete)     E[X] = ∫_{−∞}^{∞} x · f(x) dx   (continuous)
  • x — each value the variable can take
  • P(X = x) or f(x) dx — how much weight (probability) that value carries
  • Σ / ∫ — sum (discrete) or accumulate (continuous) value × weight
  • Why it makes sense: the mean is the balance point of the distribution — where the probability mass would balance on a pivot. How to read the result: E[X] = 3.5 for a fair die means the long-run average of many rolls is 3.5.

CLASS CORE The source's dice example: E[X] = 1·(1/6) + 2·(1/6) + … + 6·(1/6) = 21/6 = 3.5. Note that 3.5 is never rolled — the expectation is not required to be an attainable outcome. For our continuous toy f(x) = 2x on [0, 1]: E[X] = ∫₀¹ x·2x dx = 2∫₀¹ x² dx = 2·(1/3) = 2/3. source

E[aX + b] = a·E[X] + b    E[c] = c    E[X + Y] = E[X] + E[Y]
  • linearity — scaling shifts the balance point by the same scale and offset; this is used constantly in ML
  • E[c] = c — a constant is its own average
  • sum rule — expectations add, even if X and Y are dependent (no independence needed)
  • Why it makes sense: averaging is linear, so it passes through sums and scalings. How to read the result: if a reward is 2×score + 5, its expected value is 2·E[score] + 5.
Beginner trap. "3.5 is impossible on a die, so the expectation must be wrong." Expectation is a balance point, not a prediction of a single outcome. A die's outcomes are 1–6, but its long-run average is 3.5 — perfectly correct, and never rolled. The same happens in ML: the expected loss need not be any single example's loss.

UNIT 7 · VARIANCE

Variance is the spread around the balance point

CLASS CORE Variance measures uncertainty — how far values deviate from the mean. It is the expected squared distance from the balance point: source

Var(X) = E[(X − μ)²]   where μ = E[X]
  • X − μ — each value's deviation from the mean
  • (X − μ)² — squared so that deviations on both sides add instead of cancelling
  • E[·] — the probability-weighted average of those squared deviations
  • Why it makes sense: squaring punishes large deviations more than small ones and makes everything positive. How to read the result: a small variance means values hug the mean; a large one means they scatter.

CLASS CORE Squaring is awkward to compute, so the source gives the computational form — important for interviews:

Var(X) = E[X²] − (E[X])²
  • E[X²] — the average of the squared values (the second moment)
  • (E[X])² — the square of the mean
  • Why it makes sense: expanding E[(X−μ)²] gives E[X²] − 2μE[X] + μ² = E[X²] − μ². How to read the result: compute two averages instead of a sum of squared deviations.

CLASS CORE The source's dice example: E[X] = 3.5, and E[X²] = (1² + 2² + … + 6²)/6 = 91/6 ≈ 15.167, so Var(X) = 91/6 − (3.5)² = 15.167 − 12.25 ≈ 2.92. The standard deviation is σ = √Var(X) ≈ 1.71, back in the original units. source

σ = √Var(X)
  • σ — the standard deviation: spread in the same units as X
  • √Var(X) — undo the squaring that variance introduced
  • Why it makes sense: variance is in squared units (a "squared die" makes no sense), so we take a square root to return to the data's units. How to read the result: σ ≈ 1.71 means a typical roll sits about 1.7 away from 3.5.
Beginner trap. "Variance ≈ 2.92 means values are about ±2.92 from the mean." No — variance is in squared units. The quantity in X's units is the standard deviation, σ ≈ 1.71. Reporting the variance when you mean the spread-in-units is the classic units error.

Variance is the heart of the bias–variance tradeoff. High variance means unstable predictions: small data changes swing the model (overfitting). Regularization, ensembling, and dropout all trade a little bias for less variance. The standard deviation is also the scale of the noise you assume when you write a Gaussian likelihood. source

UNIT 8 · COVARIANCE & CORRELATION

Covariance asks whether two budgets move together

CLASS CORE Covariance measures whether two variables move together. It averages the product of their deviations from their own means: source

Cov(X, Y) = E[(X − E[X])(Y − E[Y])]
  • X − E[X] — how far X sits above or below its mean
  • Y − E[Y] — the same for Y
  • product — positive when both are above (or both below) their means; negative when they disagree
  • Why it makes sense: averaging that product turns "do they move together?" into a single number. How to read the result: positive → move together; negative → move oppositely; near zero → little linear relationship.
CovarianceMeaningExample
PositiveMove togetherMore study hours → higher scores
NegativeMove oppositelyMore speed → less travel time
ZeroNo linear relationSee the trap below

CLASS CORE Covariance's size depends on the units (change one variable to different units and the covariance changes), so the source normalizes it into correlation: source

Corr(X, Y) = Cov(X, Y) / (σ_X · σ_Y)   ∈ [−1, 1]
  • Cov(X, Y) — the raw joint movement
  • σ_X, σ_Y — the two standard deviations, which set the natural scale
  • [−1, 1] — after dividing by the scales, the result is unit-free: −1 is perfect opposition, +1 perfect agreement, 0 no linear relation
  • Why it makes sense: dividing out the two spreads removes the units and makes comparisons fair. How to read the result: ρ = 0.8 is a strong positive linear relationship regardless of the variables' units.
Beginner trap. "Cov(X, Y) = 0 means X and Y are independent." No — zero covariance means no linear relationship, not no relationship. The source's counterexample: let Y = X² with X symmetric around zero. Then X and Y are clearly dependent (Y is determined by X), yet their covariance is exactly 0. Uncorrelated is weaker than independent.

Where probability runs in real ML

ML LINK The source closes with two systems built directly on this unit's ideas. PCA (Principal Component Analysis) uses the covariance matrix to find the directions of maximum variance; the eigenvectors of that matrix are the principal components. Gaussian models depend on mean and variance, and a multivariate Gaussian additionally uses the covariance. source

Σ = [[ Var(X), Cov(X, Y) ], [ Cov(X, Y), Var(Y) ]]
  • diagonal entries — the variances of each variable (how spread each is on its own)
  • off-diagonal entries — the covariance (how the two move together); the matrix is symmetric
  • Why it makes sense: a single matrix stores every pairwise spread and joint movement, which is exactly what PCA and multivariate Gaussians need. How to read the result: a large off-diagonal (relative to the diagonal) means the two variables are strongly coupled. source (figure recovered)
f(x) = (1 / (σ√(2π))) · e^{ −(x − μ)² / (2σ²) }
  • μ — the mean: where the bell is centred

SYNTHESIS

The whole lesson in one arc

Look back at the concept map. A random variable labels outcomes with numbers; it is discrete (a PMF hands out lumps) or continuous (a PDF packs density, and only areas are probabilities). The CDF is the running total of either, and the conversion at the centre of the lesson says the CDF is the area under the PDF while the PDF is the slope of the CDF. From there, the expectation is the balance point, the variance is the spread around it, and the covariance says whether two variables move together. Put variance and covariance in a matrix and you have PCA and the multivariate Gaussian.

Three threads to carry forward: (1) area and accumulation — probability for continuous variables is area, and the CDF is accumulated area; (2) summary numbers — mean, variance, and covariance compress a whole distribution into a few interpretable values; (3) the linear view — covariance is linear dependence, which is why PCA (linear) can miss non-linear structure and why "uncorrelated" is weaker than "independent."

GLOSSARY

Every term, six ways

probability
Simple: how likely something is, on a scale from 0 to 1. Precise: a number in [0,1] assigned to an event measuring its chance of occurring. Intuition: a budget of certainty shared out over outcomes. Example: a fair coin has P(heads) = 0.5. Related: uncertainty, random variable, distribution. In practice/ML: every model's output is a probability (spam score, next-token, click).
uncertainty
Simple: not knowing the outcome for sure. Precise: the condition modelled by a probability distribution over outcomes. Intuition: the reason probability exists. Example: tomorrow's rainfall is uncertain. Related: probability, random variable. In practice/ML: predictive uncertainty drives when a model abstains or flags risk.
random variable
Simple: a rule that turns an outcome into a number. Precise: a function X: Ω → ℝ mapping each outcome to a real value. Intuition: a numerical label for randomness. Example: X = the number on a rolled die. Related: discrete, continuous, sample space. In practice/ML: every feature and every prediction is a random variable.
sample space
Simple: all the things that could happen. Precise: the set Ω of all possible outcomes of a random process. Intuition: the menu before you order. Example: Ω = {1, 2, 3, 4, 5, 6} for a die. Related: outcome, random variable. In practice/ML: the set of possible labels or classes.
outcome
Simple: a single result. Precise: one element of the sample space; an event is a set of outcomes. Intuition: what actually happened. Example: rolling a 4. Related: sample space, event. In practice/ML: one observed data point or one generated token.
discrete random variable
Simple: a variable with countable values. Precise: an RV taking finitely or countably many values, with probability attached to exact values. Intuition: values you can list. Example: number of emails received. Related: PMF, continuous. In practice/ML: class labels, token indices, counts.
continuous random variable
Simple: a variable that can take any value in a range. Precise: an RV over an interval, where P(X = x) = 0 for every single point. Intuition: values you measure, not count. Example: height, temperature, time. Related: PDF, CDF. In practice/ML: scores, embeddings, physical measurements.
probability distribution
Simple: how probability is shared over a variable's values. Precise: the function (PMF, PDF, or CDF) describing the probabilities of an RV's values. Intuition: the shape of the uncertainty. Example: the uniform, Gaussian, or dice distribution. Related: PMF, PDF, CDF. In practice/ML: the output layer's softmax is a distribution.
probability mass function (PMF)
Simple: the probability of each exact value of a discrete variable. Precise: P(X = x) for each value, with masses in [0,1] summing to 1. Intuition: lumps of probability at the values. Example: P(X = x) = 1/6 for a fair die. Related: discrete, PDF, CDF. In practice/ML: the next-token distribution is a PMF.
probability density function (PDF)
Simple: a curve whose area gives probability for a continuous variable. Precise: a non-negative f with ∫f = 1, where P(a ≤ X ≤ b) = ∫ₐᵇ f. Intuition: how thickly probability is packed. Example: U(0,1) has f(x) = 1; f(x) = 2x is another. Related: continuous, density, CDF. In practice/ML: Gaussian likelihoods are densities.
cumulative distribution function (CDF)
Simple: the running total of probability up to x. Precise: F(x) = P(X ≤ x); non-decreasing, in [0,1], →0 left and →1 right. Intuition: how much budget is spent by x. Example: U(0,1) has F(x) = x. Related: PMF, PDF, fundamental theorem. In practice/ML: thresholds, calibration, inverse-CDF sampling.
density
Simple: the height of a PDF. Precise: the value f(x) of a density at x; not a probability and may exceed 1. Intuition: concentration, not amount. Example: f(x) = 2x reaches 2 at x = 1. Related: PDF, area under the curve. In practice/ML: likelihood values are densities.
area under the curve
Simple: the probability captured by a slice of a density. Precise: ∫ₐᵇ f(x) dx = P(a ≤ X ≤ b). Intuition: how much of the density sits over the interval. Example: ∫₀^{0.5} 2x dx = 0.25. Related: PDF, integral, CDF. In practice/ML: the area beyond a threshold is an error rate.
support
Simple: where a distribution is not zero. Precise: the set of values with non-zero mass or density. Intuition: the region the variable can occupy. Example: [0, 1] for U(0,1). Related: PDF, PMF. In practice/ML: bounded supports motivate logit transforms.
uniform distribution
Simple: every value in a range is equally likely. Precise: U(0,1) has f(x) = 1 on [0,1] and F(x) = x. Intuition: a flat density. Example: a random number generator. Related: PDF, CDF. In practice/ML: random initialization uses uniforms.
fundamental theorem (of probability conversion)
Simple: the CDF is the area under the PDF; the PDF is the slope of the CDF. Precise: F(x) = ∫_{−∞}^{x} f(t) dt and f(x) = dF/dx; hence P(a ≤ X ≤ b) = F(b) − F(a). Intuition: accumulate a rate to get a total, differentiate a total to get the rate. Example: f = 2x ⇔ F = x². Related: integral, derivative, CDF. In practice/ML: inverse-CDF sampling and normalizing flows rely on it.
integral
Simple: an accumulated area. Precise: the limit of a sum of thin rectangles; ∫ₐᵇ f(x) dx is the signed area under f from a to b. Intuition: adding up infinitely many thin slices. Example: ∫₀¹ 2x dx = 1. Related: area under the curve, derivative, CDF. In practice/ML: continuous expectation and probability are integrals.
derivative
Simple: the slope — how fast something changes. Precise: dF/dx is the local rate of change of F. Intuition: the steepness of a curve at a point. Example: d/dx(x²) = 2x. Related: integral, PDF, density. In practice/ML: the PDF is the derivative of the CDF.
left limit
Simple: the value a function approaches from below. Precise: F(x⁻) = lim of F as it approaches x from the left. Intuition: the running total just before x. Example: for a fair die, F(3⁻) = F(2) = 1/3. Related: CDF, PMF. In practice/ML: recovering discrete masses from a step CDF.
expectation (expected value)
Simple: the long-run average. Precise: E[X] = Σ x P(X=x) (discrete) or ∫ x f(x) dx (continuous). Intuition: the balance point of the probability budget. Example: a fair die has E[X] = 3.5. Related: mean, variance, linearity. In practice/ML: expected loss is what training minimizes.
mean
Simple: the average value, μ. Precise: synonym for E[X]. Intuition: the centre of mass of the distribution. Example: E[X] = 2/3 for f(x) = 2x. Related: expectation, variance. In practice/ML: a Gaussian's first parameter.
linearity of expectation
Simple: averaging passes through sums and scalings. Precise: E[aX + b] = aE[X] + b and E[X + Y] = E[X] + E[Y], even if dependent. Intuition: the average of a shifted/scaled quantity shifts/scales the same way. Example: if reward = 2·score + 5, E[reward] = 2E[score] + 5. Related: expectation. In practice/ML: decomposing complex expected losses.
variance
Simple: how spread out the values are. Precise: Var(X) = E[(X − μ)²] = E[X²] − (E[X])². Intuition: the expected squared distance from the mean. Example: a fair die has Var ≈ 2.92. Related: standard deviation, spread, bias–variance. In practice/ML: unstable predictions = high variance = overfitting.
standard deviation
Simple: spread in the data's own units. Precise: σ = √Var(X). Intuition: "about this far from the mean." Example: a fair die has σ ≈ 1.71. Related: variance, spread. In practice/ML: the scale of Gaussian noise.
spread
Simple: how widely values scatter. Precise: the dispersion measured by variance or standard deviation. Intuition: tight cluster vs wide fan. Example: the same mean with growing spread in the variance lab. Related: variance, standard deviation. In practice/ML: feature scaling normalizes spread.
computational formula (variance)
Simple: a quicker way to get variance. Precise: Var(X) = E[X²] − (E[X])². Intuition: two averages instead of a sum of squared deviations. Example: 91/6 − 3.5² ≈ 2.92 for a die. Related: variance, second moment. In practice/ML: a standard interview identity.
bias–variance tradeoff
Simple: models can err by being too simple or too jumpy. Precise: the decomposition of expected error into bias² (systematic) and variance (sensitivity to data). Intuition: a rigid model underfits; a twitchy model overfits. Example: a deep tree has high variance. Related: variance, overfitting. In practice/ML: regularization and ensembling trade bias for variance.
covariance
Simple: whether two variables move together. Precise: Cov(X,Y) = E[(X − E[X])(Y − E[Y])]. Intuition: the average product of the two deviations. Example: study hours and scores have positive covariance. Related: correlation, covariance matrix, independence. In practice/ML: the raw material of PCA and Gaussian models.
correlation
Simple: covariance rescaled to [−1, 1]. Precise: Corr(X,Y) = Cov(X,Y)/(σ_X σ_Y). Intuition: strength and direction of linear relationship, unit-free. Example: ρ = 0.8 is a strong positive relationship. Related: covariance, independence. In practice/ML: feature-correlation heatmaps guide feature selection.
independence
Simple: knowing one variable tells you nothing about the other. Precise: X and Y are independent if P(X, Y) = P(X)P(Y) for all values. Intuition: no information leaks between them. Example: two separate dice rolls. Related: uncorrelated, covariance. In practice/ML: the i.i.d. assumption in many models.
uncorrelated
Simple: no linear relationship. Precise: Cov(X,Y) = 0 (equivalently Corr = 0). Intuition: the cloud is not tilted. Example: Y = X² with X symmetric about 0. Related: independence, covariance. In practice/ML: whitening decorrelates but does not make features independent.
PCA (Principal Component Analysis)
Simple: finding the directions along which data varies most. Precise: an eigen-decomposition of the covariance matrix; the eigenvectors are the principal components and the eigenvalues are the variances along them. Intuition: rotate the axes so the first axis catches the most spread. Example: reducing 100 features to 2 for a scatter plot. Related: covariance matrix, eigenvector, principal component. In practice/ML: dimensionality reduction, visualization, whitening.
covariance matrix
Simple: a table of every variable's variance and pairwise covariance. Precise: Σ with diagonal variances and off-diagonal covariances; symmetric. Intuition: the spread-and-tilt summary of many variables at once. Example: [[2, 1], [1, 2]] has eigenvalues 3 and 1. Related: covariance, PCA, multivariate Gaussian. In practice/ML: the input to PCA and to multivariate Gaussian models.
eigenvector
Simple: a direction a matrix only stretches, never turns (Class 2's word, reused). Precise: a vector v with Mv = λv for some scalar λ (the eigenvalue). Intuition: the special directions of a transformation. Example: for [[2,1],[1,2]], v = (1,1) with λ = 3. Related: covariance matrix, principal component. In practice/ML: PCA's principal components are eigenvectors.
principal component
Simple: a direction of maximum variance. Precise: an eigenvector of the covariance matrix, ordered by its eigenvalue (variance). Intuition: the "long axis" of the data cloud. Example: the rising diagonal when features are positively correlated. Related: PCA, eigenvector, covariance matrix. In practice/ML: the new axes after PCA projection.
Gaussian (normal) distribution
Simple: the bell curve. Precise: a continuous distribution with density (1/(σ√(2π)))·e^{−(x−μ)²/(2σ²)}, determined by μ and σ. Intuition: values cluster near the mean and thin out symmetrically. Example: measurement noise. Related: mean, variance, multivariate Gaussian. In practice/ML: noise models, Gaussian processes, GMMs.
multivariate Gaussian
Simple: a bell over several variables at once. Precise: a Gaussian with a mean vector and a covariance matrix. Intuition: a tilted, stretched bell in higher dimensions. Example: a 2-D Gaussian with correlated coordinates. Related: covariance matrix, Gaussian. In practice/ML: latent spaces, Kalman filters, Gaussian mixture models.
language model
Simple: a model that predicts the next token. Precise: a system that outputs a probability distribution over a vocabulary given context. Intuition: autocomplete that weighs every possible next word. Example: the "world 0.41, everyone 0.22" table. Related: PMF, token distribution. In practice/ML: chatbots and text generators.
token distribution
Simple: the probabilities a language model gives to the next token. Precise: a PMF over the vocabulary produced at each step. Intuition: the ranked shortlist of next words. Example: P(world) = 0.41. Related: PMF, language model. In practice/ML: sampling and temperature shape it.
fraud detection
Simple: scoring how likely a transaction is fraudulent. Precise: estimating P(Fraud | transaction features) and thresholding it. Intuition: a risk score per transaction. Example: 0.02 → safe; 0.95 → suspicious. Related: probability, conditional probability. In practice/ML: the classic probabilistic classifier application.
recommendation system
Simple: a system that ranks items for a user. Precise: it estimates P(User Likes Item) and ranks by that probability. Intuition: probability ranking in disguise. Example: Netflix's "because you watched…". Related: probability, PMF. In practice/ML: ranking is sorting by predicted probability.
